INSERTS DA COLEÇÃO catalogo — ESTANTE PÚBLICA

Este documento reúne os registros dos livros utilizados para popular a coleção "catalogo" do banco de dados MongoDB do projeto Estante Pública.

INSTRUÇÕES

1. Abra o MongoDB Compass e acesse o banco de dados utilizado pelo projeto.
2. Selecione a coleção "catalogo".
3. Abra a opção "ADD DATA" e escolha "Insert Document" ou utilize o MongoDB Shell.
4. Para inserir todos os livros de uma só vez pelo MongoDB Shell, copie e execute o comando insertMany abaixo.

Observação: o registro de Moby Dick apareceu duas vezes no conteúdo enviado, com o mesmo _id. Ele foi incluído apenas uma vez neste documento para evitar uma tentativa de inserir um identificador duplicado.
